光语助手（Lumina Assist）

一、技术方案

两种工作模式，自动切换

APP 有两种工作模式，根据网络情况自动切换：

功能最全，用云端AI大模型，识别更准联网模式（正常）：

用手机本地的小模型，功能少一些但能用离线模式（断网时）：

切换时会有语音提示，比如"网络不佳，已切换至离线模式"。网络恢复后自动切回来。

用什么技术开发

手机端：鸿蒙系统（OpenHarmony 5.0），用 ArkTS 语言开发

后端服务器：Python（FastAPI 框架）

云端AI：通义千问大模型（识别图片）、阿里云语音合成（把文字读出来）

离线模型：手机本地的轻量模型（断网时用）

安全存储：用鸿蒙系统的安全密钥库保存密码

二、核心功能说明

1. 手势快捷操作（重点新功能）

解决什么问题：视障用户看不见按钮，找按钮很困难。用手势直接敲屏幕就能启动功能，不用找按钮。

三种手势：

直接打开药品识别敲3下屏幕：

打开物品识别敲2下屏幕：

唤醒语音助手，说话下指令长按1秒：

注意事项：

每次手势操作都有振动+语音双重提示，不会无声执行

口袋里误触会自动过滤（用距离传感器检测）

设置里可以开关手势功能

不会和手机系统的读屏功能冲突

后续会预留外接实体按键的接口

2. 界面设计

设计原则：语音优先，触控为辅。具体要求：

按钮特别大（不小于 96vp x 96vp），方便手指不灵活的老人点

高对比度配色，字大（不小于 20fp）

顶部状态条有4种颜色提示：聆听中（蓝）、思考中（橙）、播报中（绿）、出错（红）

不要复杂弹窗和广告

3. 药品识别流程

完整流程：触发识别 -> 打开相机（振动+语音提示） -> 自动拍照 -> 上传识别 -> 语音播报结果

结果展示：

药品名称、适应症、用法用量、禁忌风险

高风险提醒用红色标注（如"饭后服用""药物冲突"）

每次识别都会播报免责声明："识别仅供参考，不能代替医生"

可以继续语音追问，比如问"这个药能和XX一起吃吗"

异常处理：

相机权限没开：提示"请授予相机权限"

太暗拍不清：提示"光线太暗，请到明亮处拍摄"

没拍到药品：提示"没识别到药品，请重新对准"

4. 物品识别

拍东西，告诉你是什么、在哪里

联网时描述更详细，断网时只能简单分类

5. 文档朗读

拍纸质文档，提取文字，分段读给你听

可以暂停、继续、上一段、下一段

6. 语音助手

说一句话，AI帮你拆解成多个任务执行

比如："打给女儿并且叫车去医院" -> 自动拆成两个任务

每一步执行都有语音播报进度

失败了也会告诉你原因

7. 设置页面

语音速度和音色调节

手势开关

离线模式手动切换

版本号和免责声明

三、隐私和安全

密码密钥加密保存，不会明文存在手机里

拍照图片识别完就删，不在云端永久保存

相机、麦克风权限每次使用前都会检查

日志不记录用户照片和原始录音

退出APP时自动清空内存中的密钥

四、性能要求

拍照到出结果，最多3秒联网识别：

500毫秒以内离线识别：

300毫秒内开始发声语音播报：

200毫秒内手势响应：

不超过800MB，不能越用越卡内存控制：

五、出错怎么办

视障用户看不到错误弹窗，所以所有错误都必须用语音说出来：

网络/服务器出错："服务暂时出错，请稍后重试"

麦克风被占："麦克风被其他应用占用，请关闭其他录音软件"

相机被占："相机被其他应用占用"

APP出错不闪退，语音提示后回到首页
